# Camera

StudioX extension for a shared camera manager.

* **Window menu → Camera** shows the selected camera. There is no sidebar tab.
* Connect one or more cameras. The preview follows the active camera.
* Blockly category **Camera**: capture image, resize, and convert to RGB, BGR, gray, or HSV.

Install `requirements.txt` into an environment named `camera`. Blockly programs call this backend through `STUDIOX_PORT`.
